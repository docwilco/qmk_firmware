# encoder_onekey

![Breadboard with rPi Pico, a single rotary encoder with built in switch, and
some diodes](PXL_20231209_162218563.jpg)

While technically not a keyboard, this is a single rotary encoder with a built
in switch. It is meant to demonstrate how you can use a rotary encoder that's
wired into the keyboard matrix. 

The encoder part is wired to `[0, 1]` (in the keyboard matrix) and `[0, 2]` with
A and B terminals to different columns, and C terminal to the same row.

The "keystrokes" generated by the encoder are translated by
`process_record_user()` in `keymap.c` to calls to `encoder_update_user()`, also
in `keymap.c`. The `encoder_update_user()` function then calls `tap_code` to
send `KC_PGUP` or `KC_PGDN` to the computer. As per the usual `encoder`
functionality in QMK. You can change the keycodes to `KC_VOLU` and `KC_VOLD` if
you want to control the volume instead of scrolling.

The switch part is wired to `[0, 0]` for bootmagic purposes. An encoder without
detents might be "pressing down" a key because only 1 out of 4 states is _not_
connecting A or B to C. And 2 out of 4 will connect a specific terminal, so if A
or B are wired to `[0, 0]` there's a 50% chance of triggering bootmagic when
plugging in.

## Wiring diagram
![Alt text](wiring_diagram.png)

If you're using the `info.json` as is, wire the above diagram to your Pico like
this:

* `COL0` -> `GP22`
* `ROW0` -> `GP19`
* `ROW1` -> `GP20`
* `ROW2` -> `GP21`

Of course, you can wire it up any way you want if you change info.json. You can
even put in a different microcontroller. Just adjust `info.json` accordingly.

## General Info

* Keyboard Maintainer: [DocWilco](https://github.com/DocWilco)
* Hardware Supported: Handwired Raspberry Pi Pico & any rotary encoder. Built in
  switch is optional, but don't put it on `[0, 0]`, see above.

## Building and flashing
Make example for this keyboard (after setting up your build environment):

    qmk compile -kb handwired/onekey/encoder_matrix

Flashing example for this keyboard:

    qmk flash -kb handwired/onekey/encoder_matrix

See the [build environment
setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make
instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more
information. Brand new to QMK? Start with our [Complete Newbs
Guide](https://docs.qmk.fm/#/newbs).

## Bootloader

Enter the bootloader in 3 ways:

* **Bootmagic reset**: Hold down the rotary encoder and plug in the keyboard
* **Physical bootsel button**: Hold the button on the Raspberry Pi Pico (near
  the USB port) and plug in the keyboard.
* **Keycode in layout**: Map the switch to `QK_BOOT` instead of `QK_ESC` in `keymap.c`
